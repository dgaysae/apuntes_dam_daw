El término ***hardware*** se puede traducir al castellano como "ferretería". Así puedes hacerte una idea más clara de lo que puede significar en el campo de la informática. Cuando decimos que el hardware se refiere a la parte **tangible** de un equipo informático, nos referimos literalmente a lo que se puede tocar: teclado, discos, placa base, chips, cableado, etc.

El hardware como tal no sirve para nada si no hay un software que le diga qué debe hacer. Es como construir un coche y dejarlo en el concesionario. Si no hay un conductor que lo utilice, ¿para qué sirve?

De la misma forma, el software tiene sentido al instalarse sobre un hardware y ejecutarlo en él. Por eso decimos que **el software se ejecuta sobre el hardware**. Pero esto no fue siempre así. Veamos algo de historia.

Los primeros ordenadores trabajaban con **programas cableados**, estableciendo a mano las conexiones entre las distintas unidades. No existían pantallas donde los programadores viesen qué estaba sucediendo ni teclados con los que introducir las órdenes. De esta forma, cuando se quería hacer un nuevo programa o modificar uno existente era necesario cambiar la organización de los componentes del sistema.

La publicación de la [arquitectura de Von Neumann](https://es.wikipedia.org/wiki/Arquitectura_de_Von_Neumann) en 1945 supuso una revolución, ya que planteaba un modelo de propósito general. Es decir, una máquina que pudiese ejecutar distintos programas **sin necesidad de cambiar su estructura**.

Para ello, [John von Neumann](https://es.wikipedia.org/wiki/John_von_Neumann) propuso la siguiente estructura general para un ordenador:

![ud01_ed_01_von_neumann.png](/img/user/adjuntos/1DAM_ED/Unidad_01/ud01_ed_01_von_neumann.png)

Esta máquina es capaz de ejecutar **instrucciones** y órdenes elementales llamadas **instrucciones de máquina**, que deben almacenarse en la memoria principal para poder ser leídas y ejecutadas por la CPU.

La relación entre el hardware basado en esta arquitectura y el software se puede ver en la siguiente figura:

![ud01_ed_02_ubicacion_so.png](/img/user/adjuntos/1DAM_ED/Unidad_01/ud01_ed_02_ubicacion_so.png)

Como ya se ha indicado anteriormente, el SO es un software de sistema que facilita el uso del ordenador de forma **eficiente y segura**. Se ejecuta directamente **sobre el hardware** y le comunica las peticiones (**llamadas al sistema**)  de las demás aplicaciones software.

**Sobre el SO** se ejecuta el **software de aplicación**, que hace sus peticiones al SO (llamadas al sistema) a través de una interfaz para que éste dé las órdenes oportunas al hardware y realice las tareas solicitadas.

Las herramientas que aprenderemos a manejar en este módulo, es decir, el **software de desarrollo**, son parte de ese **software de aplicación**.
