La **refactorización** es el proceso de reestructurar el código existente sin cambiar su comportamiento externo, con el objetivo de mejorar su legibilidad, mantenibilidad y eficiencia. Los IDEs modernos automatizan esta tarea, garantizando que todos los cambios (nombres, ubicaciones, firmas) se propaguen correctamente a través de todo el proyecto.

Aunque **Renombrar** (*Rename*) es la refactorización más común (cambia el nombre de variables, métodos o clases y actualiza todas sus referencias), existen otras herramientas muy útiles a la hora de refactorizar nuestro código:

| Nombre de Refactorización | Descripción | Propósito Común |
| ----- | ----- | ----- |
| **Extraer método** (*Extract method*) | Toma un bloque de código seleccionado (generalmente 3 o más líneas) y lo convierte en una nueva función/método, reemplazando el bloque original por una llamada a esa nueva función. | Eliminar código duplicado y reducir la complejidad de métodos largos. |
| **Extraer variable/constante** (*Extract variable/constant*) | Reemplaza una expresión compleja, o un valor mágico (número o cadena sin explicación) con una nueva variable o constante nombrada. | Mejorar la legibilidad y claridad de las expresiones. |
| **Extraer clase/interfaz** (*Extract class/interface*) | Mueve un conjunto de responsabilidades, campos y métodos de una clase muy grande a una nueva clase o interfaz independiente. | Aplicar el Principio de Responsabilidad Única (SRP). |
| **Mover** (*Move*) | Traslada una clase, un método o un paquete completo a una nueva ubicación, actualizando automáticamente todos los `import` y referencias en todo el proyecto. | Mejorar la organización del proyecto. |
| **Cambiar firma** (*Change signature*) | Permite añadir, eliminar o reordenar los parámetros de un método o constructor, actualizando automáticamente todas las llamadas a ese método. | Adaptar APIs de métodos a nuevos requisitos sin romper el código. |

Veámoslo un ejemplo de **extraer método**.

Imaginemos un método en Java que realiza varias tareas seguidas, siendo difícil de leer:

```java
// Código inicial (bastante malo)
public void procesarPedido(Pedido p) {
    // Tarea A: cálculo de impuestos (5 líneas)
    double totalSinImpuestos = p.getPrecio() * p.getCantidad();
    double impuestos = totalSinImpuestos * 0.21;
    double totalFinal = totalSinImpuestos + impuestos;
    
    // Tarea B: validación de stock (4 líneas)
    if (almacen.comprobarStock(p.getProducto()) < p.getCantidad()) {
        System.out.println("No hay suficiente stock.");
        return;
    }
    
    // Tarea C: actualización en BDD (2 líneas)
    bd.guardarFactura(p, totalFinal);
}
```

Si seleccionamos las 5 líneas de la "Tarea A" y usamos la opción **Refactorizar > Extraer > Método** y le damos el nombre `calcularPrecioFinal`, obtendríamos el siguiente código mejorado:

```java
public void procesarPedido(Pedido p) {
    // Tarea A: Cálculo de impuestos
    double totalFinal = calcularPrecioFinal(p); // ¡Mucho más claro!

    // Tarea B: Validación de Stock
    if (almacen.comprobarStock(p.getProducto()) < p.getCantidad()) {
        System.out.println("No hay suficiente stock.");
        return;
    }
    
    // Tarea C: Actualización en BDD
    bd.guardarFactura(p, totalFinal);
}

// NUEVO MÉTODO GENERADO
private double calcularPrecioFinal(Pedido p) {
    double totalSinImpuestos = p.getPrecio() * p.getCantidad();
    double impuestos = totalSinImpuestos * 0.21;
    return totalSinImpuestos + impuestos;
}
```

Además se recomienda no hardcodear valores en el código. Es conveniente crear una constante con un nombre claro. En el código anterior, seleccionamos `0.21` y usamos **Refactorizar > Extraer > Constante** para crear la constante `PORCENTAJE_IMPUESTOS`:

```java
public void procesarPedido(Pedido p) {
    // Tarea A: Cálculo de impuestos
    double totalFinal = calcularPrecioFinal(p); // ¡Mucho más claro!

    // Tarea B: Validación de Stock
    if (almacen.comprobarStock(p.getProducto()) < p.getCantidad()) {
        System.out.println("No hay suficiente stock.");
        return;
    }
    
    // Tarea C: Actualización en BDD
    bd.guardarFactura(p, totalFinal);
}

// NUEVO MÉTODO GENERADO
private double calcularPrecioFinal(Pedido p) {
    final double PORCENTAJE_IMPUESTOS = 0.21;

    double totalSinImpuestos = p.getPrecio() * p.getCantidad();
    double impuestos = totalSinImpuestos * PORCENTAJE_IMPUESTOS;
    return totalSinImpuestos + impuestos;
}
```

La refactorización no solo hace el código más legible, sino que facilita la prueba y el mantenimiento de cada pequeña función de forma independiente.
