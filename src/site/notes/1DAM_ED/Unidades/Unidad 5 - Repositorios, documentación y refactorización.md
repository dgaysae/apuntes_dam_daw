En las unidades anteriores hemos aprendido a **escribir código** y a utilizar entornos de desarrollo para **depurarlo**. Sin embargo, en el mundo profesional, el software **no se escribe una sola vez ni lo hace una sola persona**.

Los contenidos de esta unidad son el puente entre "saber programar" y "**saber trabajar**" usando las herramientas y conocimientos que proporcian la ingeniería de software. Con ellos vamos a aprender a:

* **Gestionar cambios** en nuestro código con los **sistemas de control de versiones**.  
  Código, documentos y otros ficheros de información suelen gestionarse de forma poco recomendable. ¿Tienes varias carpetas o documentos de distintas versiones del mismo contenido y con nombres como **proyecto\_final\_v2\_definitivo\_v1.zip**, **proyecto\_final\_v2\_definitivo\_v1\_BUENO.zip** o **proyecto\_final\_v2\_definitivo\_ESTA\_VEZ\_SI.zip**?

  Esto tiene que acabar...

* **Limpiar el código**.  
  Para evitar la deuda técnica, aprenderemos a aplicar la refactorización para que el código sea más fácil de mantener.

* **Documentación útil**.  
  Generar documentación automática para que otros, o nosotros mismos en el futuro, entiendan qué hace el código.
