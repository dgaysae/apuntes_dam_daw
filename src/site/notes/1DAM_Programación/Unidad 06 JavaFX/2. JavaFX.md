**JavaFX** es una plataforma de interfaz de usuario rica y moderna para aplicaciones de escritorio Java. A diferencia de Swing, JavaFX utiliza una arquitectura basada en **gráficos de escena** (*Scene Graph*).

Los componentes gráficos en JavaFX se llaman **nodos** (*Node*) y se organizan en una jerarquía de árbol.

JavaFX tiene múltiples ventajas sobre Swing, como, por ejemplo:

* Permite una manipulación más sencilla de la estructura de la interfaz gráfica y facilita la animación y los efectos visuales.

* Tiene un diseño más moderno y estilizado. En concreto, permite el uso de CSS para personalizar la apariencia de la interfaz de usuario.

* Organización del código más fácil de seguir y de leer.

* Simplificación de la gestión de eventos.

* API de multimedia integrada para reproducir audio o video de manera nativa.

* Soporte para arrastrar y soltar.

A pesar de estas ventajas indudables, hay que tener en cuenta que existen muchísimas aplicaciones Java que están funcionando con Swing, que es una tecnología mucho más estable y madura, por lo que deberías conocer ambas formas de crear interfaces gráficos si vas a dedicarte profesionalemente al desarrollo de aplicaciones con Java.
