Vamos a enumerar los elementos típicos de cualquier aplicación JavaFX. En la siguiente sección, veremos muchos de estos elementos en un ejemplo concreto, para que sean más fáciles de asimilar.

Todas las aplicaciones JavaFX suelen tener:

1. **Una clase principal (`Main`):** La aplicación JavaFX debe tener una clase principal que extiende `javafx.application.Application`. En esta clase se ubica el método **`main()`**. La clase principal es la responsable de iniciar la aplicación y cargar la escena (o ventana) de inicio.

2. **`Stage` y `Scene`:** Una `Stage` es una ventana de la aplicación. Las aplicaciones JavaFX deben tener al menos una `Stage`, pero pueden tener varias. La `Scene` contiene la jerarquía de nodos que se mostrarán en dentro de la `Stage`.

3. **Controlador:** La lógica de la interfaz de usuario y la manipulación de eventos se gestionan a menudo mediante un controlador. Un controlador no es más que una clase que se asocia con un archivo FXML y se encarga de manejar eventos y la lógica de la interfaz de usuario (Los archivos FXML son archivos XML que se utilizan para definir la interfaz de usuario de forma declarativa; enseguida hablamos de ellos).

4. **Modelo:** Aunque JavaFX no impone una estructura de modelo-vista-controlador (MVC) estricta, muchos desarrolladores eligen seguir un diseño similar. El modelo, en esta arquitectura, representa los datos y la lógica de la aplicación.

5. **Vistas:** Las vistas son los elementos visuales de la interfaz de usuario. Pueden definirse en código Java o en archivos FXML.

6. Los **controles y nodos** de JavaFX (botones, tablas, etc.) se utilizan para construir la interfaz de usuario.

7. **CSS (opcional):** Se pueden aplicar hojas de estilo CSS para personalizar la apariencia de los nodos y controles.

8. **Eventos y Listeners:** JavaFX, como Swing, utiliza un sistema de eventos para manejar la interacción del usuario. Se pueden asociar métodos en el controlador con eventos en la interfaz de usuario, como clics de botón o cambios en campos de texto.

9. **Propiedades:** JavaFX ofrece propiedades observables y *bindings*, lo que facilita la actualización automática de la interfaz de usuario en respuesta a cambios en los datos del modelo.
