Los nodos, como hemos visto en el ejemplo, son los objetos gráficos que se pueden insertar en el interfaz de usuario. A continuación mostraremos una lista de los más habituales, aunque por supuesto hay muchos más:

## 5.1. Contenedores

* **`Pane`**: es una clase base para todos los contenedores en JavaFX. Proporciona un área rectangular en la que se pueden colocar otros nodos.

* **`VBox`** y **`HBox`**: `VBox` (Vertical Box) y `HBox` (Horizontal Box) son contenedores que organizan sus nodos secuencialmente, ya sea en una columna vertical o en una fila horizontal.

* **`BorderPane`**: contenedor que divide su área en cinco regiones: arriba, abajo, izquierda, derecha y centro, permitiendo colocar nodos en cada una de estas regiones.

(Ver la sección *layouts* más abajo para una lista más completa de contenedores)

## 5.2. Nodos de control: botones, campos de texto y más

* **`Button`**: representa un botón que puede disparar eventos cuando se hace clic.

* **`Label`**: representa una etiqueta de texto no editable.

* **`TextField`**: es un campo de texto que permite al usuario introducir un texto.

* **`TextArea`**: es un área de texto multilínea que permite al usuario introducir un texto.

* **`CheckBox`** y **`RadioButton`**: son controles de selección que permiten al usuario elegir opciones. Como en HTML, vamos.

* **`ComboBox`**: control desplegable que permite al usuario seleccionar un elemento de una lista.

* **`ListView`** y **`TreeView`**: controles de lista que permiten al usuario ver y seleccionar elementos de una lista o una estructura de árbol, respectivamente.

Aquí tienes un ejemplo sencillo donde se usan casi todos estos nodos.

En primer lugar, tendríamos el interfaz definido en un **archivo FXML**. Observa cómo se declaran cada uno de los nodos del interfaz.

```xml
<?xml version="1.0" encoding="UTF-8"?>

<?import javafx.scene.control.*?>
<?import javafx.scene.layout.VBox?>

<VBox spacing="10" xmlns="http://javafx.com/javafx"
      xmlns:fx="http://javafx.com/fxml"
      fx:controller="nombre-del-controlador">

    <Label text="Nombre:"/>
    <TextField fx:id="nameTextField"/>

    <Label text="Mensaje:"/>
    <TextArea fx:id="messageTextArea"/>

    <CheckBox text="Acepto los términos y condiciones" fx:id="checkBox"/>

    <RadioButton text="Opción 1" fx:id="radioOption1"/>
    <RadioButton text="Opción 2" fx:id="radioOption2"/>

    <ComboBox fx:id="comboBox" promptText="Selecciona una opción">
        <items>
            <FXCollections fx:factory="observableArrayList">
                <String fx:value="Opción A"/>
                <String fx:value="Opción B"/>
                <String fx:value="Opción C"/>
            </FXCollections>
        </items>
    </ComboBox>

    <Button text="Enviar" onAction="#handleSubmit"/>
</VBox>
```

Este sería el **controlador** para ese interfaz gráfico. Hemos añadido un manejador de eventos para capturar el clic de ratón.

```java
import javafx.collections.FXCollections;
import javafx.fxml.FXML;
import javafx.scene.control.*;

public class NombreDelControlador {
    @FXML
    private TextField nameTextField;

    @FXML
    private TextArea messageTextArea;

    @FXML
    private CheckBox checkBox;

    @FXML
    private RadioButton radioOption1;

    @FXML
    private RadioButton radioOption2;

    @FXML
    private ComboBox<String> comboBox;

    @FXML
    private void handleSubmit() {
        // Obtenemos los valores de los diferentes nodos
        String name = nameTextField.getText();
        String message = messageTextArea.getText();
        boolean accepted = checkBox.isSelected();
        // Obtener el valor de RadioButton seleccionado directamente
        ToggleGroup toggleGroup = radioOption1.getToggleGroup();
        RadioButton selectedRadio = 
                       (RadioButton) toggleGroup.getSelectedToggle();
        String radioOption = 
                       selectedRadio == null ? "" : selectedRadio.getText();
        String comboBoxOption = comboBox.getValue();

        // Mostramos esos valores por la consola
        System.out.println("Nombre: " + name);
        System.out.println("Mensaje: " + message);
        System.out.println("Aceptar términos: " + accepted);
        System.out.println("Opción de radio: " + radioOption);
        System.out.println("Opción de ComboBox: " + comboBoxOption);
    }
}
```

Y, por último, esta sería la clase principal:

```java
import javafx.application.Application;
import javafx.fxml.FXMLLoader;
import javafx.scene.Parent;
import javafx.scene.Scene;
import javafx.stage.Stage;

public class Main extends Application {

    @Override
    public void start(Stage primaryStage) throws Exception{
        Parent root =
                 FXMLLoader.load(getClass().getResource("archivo.fxml"));
        primaryStage.setTitle("Ejemplo de UI con FXML");
        primaryStage.setScene(new Scene(root, 400, 400));
        primaryStage.show();
    }

    public static void main(String[] args) {
        launch(args);
    }
}
```

## 5.3. Nodos gráficos

* **ImageView**: se utiliza para mostrar imágenes.

* **Canvas**: proporciona un área en la que se pueden realizar operaciones de dibujo.

* **WebView**: permite mostrar contenido web embebido en una aplicación JavaFX.

Probablemente el más habitual es **ImageView**, que nos permite insertar imágenes en nuestra ventana. Para crear un ImageView desde FXML, el código mínimo necesario es este:

```xml
<ImageView>
    <image>
        <Image url="@mi-imagen.jpg"/>
    </image>
</ImageView>
```

Al ImageView se le pueden añadir atributos como `fitHeight` y `fitWidth` para controlar su tamaño. También es útil el atributo `preserveRatio="true"` para asegurarte de que la imagen no se deforma.

## 5.4. Menús

Para crear menús, en JavaFX se utilizan varios nodos específicos destinados a gestionar la estructura de menús y sus elementos. Aquí algunos de los nodos principales que puedes utilizar:

* **`MenuBar`**: es un contenedor que contiene objetos de tipo Menu, que a su vez contienen objetos MenuItem. Puedes agregar varios menús horizontales a una barra de menús.

* **`Menu`**: representa un menú desplegable. Puedes agregar múltiples elementos de menú (MenuItem y otros submenús) dentro de un Menu.

* **`MenuItem`**: representa un elemento de menú individual. Puede contener texto, gráficos o incluso submenús.

* **`CheckMenuItem`**: es una extensión de MenuItem que puede tener un estado de selección (marcado o desmarcado). Es útil para opciones de menú que pueden estar activadas o desactivadas.

* **`RadioMenuItem`**: es otra extensión de `MenuItem` que se utiliza en grupos de elementos de menú. Solo un RadioMenuItem de un grupo puede estar seleccionado a la vez.

* **`ContextMenu`**: es un menú contextual que se muestra en respuesta a una acción del usuario, generalmente un clic derecho.

A continuación puedes ver un ejemplo simple de uso de algunas de estas clases. En este ejemplo, vamos a crear todos los nodos desde Java, pero recuerda que también se puede hacer con un archivo FXML.

```java
import javafx.application.Application;
import javafx.scene.Scene;
import javafx.scene.control.*;
import javafx.scene.layout.VBox;
import javafx.stage.Stage;

public class MenuExample extends Application {

    @Override
    public void start(Stage primaryStage) {
        primaryStage.setTitle("Ejemplo de Menú");

        // Barra de menús
        MenuBar menuBar = new MenuBar();

        // Menú "Archivo"
        Menu fileMenu = new Menu("Archivo");

        MenuItem newItem = new MenuItem("Nuevo");
        MenuItem openItem = new MenuItem("Abrir");
        MenuItem saveItem = new MenuItem("Guardar");
        MenuItem exitItem = new MenuItem("Salir");

        fileMenu.getItems().addAll(newItem, openItem, saveItem, 
                                   new SeparatorMenuItem(), exitItem);

        // Menú "Editar"
        Menu editMenu = new Menu("Editar");

        MenuItem cutItem = new MenuItem("Cortar");
        MenuItem copyItem = new MenuItem("Copiar");
        MenuItem pasteItem = new MenuItem("Pegar");

        editMenu.getItems().addAll(cutItem, copyItem, pasteItem);

        // Menú contextual
        ContextMenu contextMenu = new ContextMenu();
        MenuItem contextItem = new MenuItem("Opción de Menú Contextual");
        contextMenu.getItems().add(contextItem);

        // Área de contenido
        TextArea textArea = new TextArea();

        // Asociación del menú contextual a la área de texto
        textArea.setContextMenu(contextMenu);

        // Asociación de menús a la barra de menús
        menuBar.getMenus().addAll(fileMenu, editMenu);

        // Diseño de la interfaz
        VBox vbox = new VBox(menuBar, textArea);
        Scene scene = new Scene(vbox, 400, 300);
        primaryStage.setScene(scene);

        primaryStage.show();
    }

    public static void main(String[] args) {
        launch(args);
    }
}
```

### Reutilizar menús

A menudo, las aplicaciones tienen varias vistas (o ventanas diferentes) que comparten el mismo menú. Si este es tu caso, no es necesario que programes el mismo menú varias veces. Para reutilizar tu menú, basta con hacer lo siguiente:

1. Diseña tu menú como una vista FXML. Puedes utilizar SceneBuilder (ver más adelante) o hacerlo a mano.

2. Guarda tu menú en un archivo llamado menu.fxml o algo parecido.

3. Inserta ese menú en cualquier otro archivo FXML escribiendo esto en el punto de tu vista donde quieras que el menú aparezca:  
  `<fx:include source="menu.fxml"/>`  

## 5.5. Controles especiales

* **`DatePicker`** y **`TimePicker`**: proporcionan controles para la selección de fechas y horas, respectivamente.

* **`ProgressBar`**: muestra una barra gráfica de progreso.

* **`Slider`**: permite al usuario seleccionar un valor de un rango continuo. 

* **`ScrollBar`**: ScrollBar proporciona una barra que se puede desplazar horizontal o verticalmente.

Aquí te muestro, a modo de ejemplo, un caso de uso sencillo de `DatePicker`.

```java
import javafx.application.Application;
import javafx.scene.Scene;
import javafx.scene.control.DatePicker;
import javafx.scene.layout.StackPane;
import javafx.stage.Stage;

public class DatePickerExample extends Application {

    @Override
    public void start(Stage primaryStage) {
        primaryStage.setTitle("Ejemplo de DatePicker");

        // Crear un DatePicker
        DatePicker datePicker = new DatePicker();

        // Crear un contenedor
        StackPane root = new StackPane();
        root.getChildren().add(datePicker);

        // Crear la escena
        Scene scene = new Scene(root, 300, 200);

        // Configurar la escena en el escenario
        primaryStage.setScene(scene);

        // Mostrar el escenario
        primaryStage.show();
    }

    public static void main(String[] args) {
        launch(args);
    }
}
```
