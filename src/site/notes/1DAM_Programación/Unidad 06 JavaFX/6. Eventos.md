Los principales eventos con los que puedes manejar las aplicaciones JavaFX son los siguientes:

* **`ActionEvent`**: Ocurre cuando se realiza una acción en un nodo interactivo, como hacer clic en un botón. El evento concreto depende del nodo. Si es un botón, `ActionEvent` es "hacer clic en el botón", por ejemplo.

* **`MouseEvent`**: Engloba eventos relacionados con el movimiento y clics del mouse, incluyendo clics simples y dobles, arrastre, entre otros.

* **`KeyEvent`**: Se activa cuando ocurre un evento de teclado, como presionar, soltar o mantener presionada una tecla.

* **`DragEvent`**: Relacionado con eventos de arrastre y suelta, se dispara durante la interacción de arrastre de un nodo.

* **`WindowEvent`**: Ocurre cuando hay cambios en el estado de la ventana, como apertura, cierre, activación, etc.

* **`ScrollEvent`**: Relacionado con eventos de desplazamiento del mouse, se activa cuando se realiza un desplazamiento con la rueda del mouse.

* **`ZoomEvent`**: Se activa durante eventos de zoom, como acercar o alejar, a menudo asociado con gestos táctiles.

* **`SwipeEvent`**: Relacionado con eventos de deslizamiento, típicamente asociados con gestos táctiles.

* **`InputMethodEvent`**: Ocurre durante eventos de entrada de método, como la composición de texto en idiomas no latinos.

* **`MediaEvent`**: Relacionado con eventos de reproducción multimedia, como inicio, pausa o finalización de la reproducción.

* **`ContextMenuEvent`**: Relacionado con la aparición y desaparición de menús contextuales.

Un evento como, por ejemplo, `MouseEvent`, puede producirse por diferentes eventos de ratón, como hacer clic, hacer doble clic o arrastrar y soltar. Para saber exactamente qué es lo que el usuario ha hecho, el manejador del evento tiene que acceder a las propiedades y métodos del evento que, como es lógico, son diferentes para cada tipo de evento. Por lo tanto, tendrás que bucear en la documentación para usar cada tipo de evento según su propio estilo.

Observa este ejemplo de manejador de evento `MouseEvent` y observa cómo nos las podemos apañar para averiguar los detalles concretos del evento:

```java
    private void handleMouseEvent(MouseEvent event) {
        if (event.getEventType() == MouseEvent.MOUSE_CLICKED) {
            System.out.println("Clic simple");
        } else if (event.getEventType()==MouseEvent.MOUSE_DOUBLE_CLICKED) {
            System.out.println("Doble clic");
        }

        int clickCount = event.getClickCount();
        if (clickCount == 1) {
            System.out.println("Clic simple");
        } else if (clickCount == 2) {
            System.out.println("Doble clic");
        }

        if (event.isPrimaryButtonDown()) {
            System.out.println("Botón izquierdo presionado");
        }

        if (event.isSecondaryButtonDown()) {
            System.out.println("Botón derecho presionado");
        }
    }
```
