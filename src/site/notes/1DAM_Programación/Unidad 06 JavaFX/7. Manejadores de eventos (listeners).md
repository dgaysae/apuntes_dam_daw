Los listeners o manejadores de eventos (EventHandlers, en terminología de JavaFX) se construyen de forma diferente si usas FXML o si montas tu interfaz directamente desde Java. Yo te recomiendo usar FXML.

## 7.1. Creando listeners con FXML  
Cuando defines EventHandlers en FXML, estás incorporando la lógica directamente en la descripción de la interfaz de usuario. Esto es mejor para mantener una separación visual entre la estructura de la interfaz y la lógica de la aplicación. Además, es mucho más fácil escribir el código así.

Crear un EventHandler desde el **archivo FXML** es tan fácil como:

```xml
<Button fx:id="myButton" text="Haz clic" onAction="#handleButtonClick"/>
```

En el **controlador** correspondiente bastará con que crear el método **`handleButtonClick()`**:

```java
public class Controller {
    @FXML
    private Button myButton;

    @FXML
    private void handleButtonClick() {
        System.out.println("Botón clicado!");
    }
}
```

## 7.2. Creado listeners con código Java  
Cuando defines `EventHandler` directamente en el código Java, estás centralizando la lógica de la aplicación en el código. Esto puede ser beneficioso cuando prefieres tener más control sobre la lógica y no quieres que la interfaz de usuario contenga demasiada información sobre el comportamiento de la aplicación, pero, en general, es más engorroso escribir el código de este modo.

El mismo ejemplo anterior se escribiría así sin usar FXML. Observa cómo se añade el `EventHandle` con el método **`setOnAction()`**:

```java
import javafx.application.Application;
import javafx.scene.Scene;
import javafx.scene.control.Button;
import javafx.stage.Stage;
  
public class Main extends Application {
  
    @Override
    public void start(Stage primaryStage) {
        Button myButton = new Button("Haz clic");

        myButton.setOnAction(event -> {
            System.out.println("Botón clicado!");
        });
  
        primaryStage.setScene(new Scene(myButton, 300, 200));
        primaryStage.setTitle("Ejemplo sin FXML");
        primaryStage.show();
    }
  
    public static void main(String[] args) {
        launch(args);
    }
}
```
