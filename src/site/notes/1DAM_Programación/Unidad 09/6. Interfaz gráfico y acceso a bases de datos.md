## 6.1. La clase `TableView`

La clase **`TableView`** es un control de **JavaFX** especializado en mostrar información de forma tabular. Por tanto, se usa mucho en aplicaciones gráficas que gestionan bases de datos.  

![ud09_tableView_01.png](/img/user/adjuntos/1DAM_Programacion/Unidad_09/ud09_tableView_01.png)

## 6.2. Cómo usar la clase `TableView`

La clase `TableView` requiere una cierta preparación previa para funcionar.

Para empezar, se debe asociar a una colección o lista de elementos. Esa colección puede ser algo tan simple como un `ArrayList` o algo más complejo como una `ObservableList`. Esta última clase, que pertenence a JavaFX y no a Java, tiene la ventaja de que cualquier actualización sobre los datos de la lista se reflejará automáticamente en la vista. En cambio, si usamos un `ArrayList`, tendremos que actualizar manualmente la vista cada vez que cambien los datos.

Vamos a ver exactamente cómo podemos usar un `TableView` basado en un `ObservableList` con un ejemplo práctico sencillo. En este ejemplo, supondremos que tenemos una tabla llamada Usuarios en una base de datos MySQL, y que esa tabla tiene tres campos:

* id, de tipo entero.
* nick, de tipo `varchar`.
* email, de tipo `varchar`.

### Paso 1: Crear una clase `Usuario`

Esta clase debe mapear los registros de la tabla Usuarios en objetos. El código será más o menos como sigue.

Observa que usamos `IntegerProperty` en lugar de `int` y `StringProperty` en lugar de `String`. Aunque se pueden usar `int` y `String`, las clases `IntegerProperty` y `StringProperty`, que son propias de JavaFX, notifican los cambios en los datos del usuario al `TableView` y nos permiten que se actualice automáticamente.

```java
import javafx.beans.property.SimpleIntegerProperty;
import javafx.beans.property.SimpleStringProperty;
import javafx.beans.property.IntegerProperty;
import javafx.beans.property.StringProperty;

public class Usuario {
    private IntegerProperty id;
    private StringProperty nick;
    private StringProperty email;

    public Usuario(int id, String nick, String email) {
        this.id = new SimpleIntegerProperty(id);
        this.nick = new SimpleStringProperty(nick);
        this.email = new SimpleStringProperty(email);
    }

    public IntegerProperty idProperty() {
        return id;
    }

    public StringProperty nickProperty() {
        return nick;
    }

    public StringProperty emailProperty() {
        return email;
    }

    // Getters y Setters
    public int getId() {
        return id.get();
    }

    public void setId(int id) {
        this.id.set(id);
    }

    public String getNick() {
        return nick.get();
    }

    public void setNick(String nick) {
        this.nick.set(nick);
    }

    public String getEmail() {
        return email.get();
    }

    public void setEmail(String email) {
        this.email.set(email);
    }
}
```

### Paso 2: Crear el `TableView` en el archivo FXML

Por supuesto, se puede trabajar sin FXML y crear el TableView por código, pero nosotros siempre preferiremos usar una vista FXML. Podría ser algo así:

```xml
<VBox fx:controller="com.ejemplo.UsuariosController">
    <TableView fx:id="tableView">
        <columns>
            <TableColumn fx:id="colId" text="ID" prefWidth="100" />
            <TableColumn fx:id="colNick" text="Nick" prefWidth="200" />
            <TableColumn fx:id="colEmail" text="Email" prefWidth="300" />
        </columns>
    </TableView>
</VBox>
```

### Paso 3: Crear el controlador

En el controlador tenemos que crear una variable para el `TableView` y una variable para cada columna del `TableView`, es decir, para cada `TableColumn`. 

También crearemos la `ObservableList` a partir de la clase `Usuario` y, por último, en el método `initialize()` asociaremos la `ObservableList` al `TableView`. A partir de eso, que solo debe realizarse una vez, cualquier cambio en los datos de la lista se reflejará en el `TableView`, y también a la inversa.

```java
import javafx.fxml.FXML;
import javafx.collections.FXCollections;
import javafx.collections.ObservableList;
import javafx.scene.control.TableColumn;
import javafx.scene.control.TableView;

public class PrimaryController {
    @FXML
    TableView tableView;

    @FXML
    private TableColumn<Usuario, Integer> colId;

    @FXML
    private TableColumn<Usuario, String> colNick;

    @FXML
    private TableColumn<Usuario, String> colEmail; 

    // Lista de usuarios en un ObservableList en lugar de un ArrayList
    private ObservableList<Usuario> usuarios =
                                    FXCollections.observableArrayList();

    // En initialize() se inicializa el TableView y se asocia a la lista de
    // usuarios. ¡Esto solo hay que hacerlo una vez!
    public void initialize() {
        // Inicializamos las columnas de la tabla.
        colId.setCellValueFactory(new PropertyValueFactory<>("id"));
        colNick.setCellValueFactory(new PropertyValueFactory<>("nick"));
        colEmail.setCellValueFactory(new PropertyValueFactory<>("email"));
        // Asignamos la ObservableList de usuarios al TableView. 
        tableView.setItems(usuarios);        
    }

    // A partir de aquí, escribiremos el resto del controlador
}
```

Como ya hemos apuntado, se puede usar un `ArrayList` convencional para la lista de datos del `TableView`, pero el `ObservableList` actualizará el `TableView` automáticamente al cambiar los datos de la lista.

ObservableList es una clase de JavaFX, no de Java, especialmente diseñada para trabajar con interfaces de usuario interactivos, que deben actualizarse automáticamente al cambiar los datos.

Existen otras clases observables en JavaFX, como `ObservableMap`, que funcionan de forma parecida, pero para mapas en lugar de listas.

Observa como las clases observables no se crean con `new`, sino con un método estático de `FXCollection`, que es otra clase propia de JavaFX.
