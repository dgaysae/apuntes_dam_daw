Hasta ahora hemos visto cada estructura por separado. En la práctica, cualquier programa real las **combina**: un bucle dentro de otro, una condición dentro de un bucle, un `try-catch` alrededor de una lectura… En este apartado vamos a construir un programa completo paso a paso, como lo haríamos en un proyecto.

## 10.1 El enunciado

> [!EXAMPLE] Adivina el número
> El programa elige un número al azar entre 1 y 100. El usuario tiene **7 intentos** para adivinarlo. Tras cada intento, el programa le dice si el número secreto es mayor o menor. Si el usuario escribe algo que no es un número, se le avisa y **no se le descuenta el intento**. Al acabar, el programa pregunta si se quiere jugar otra vez.

## 10.2 Análisis: ¿qué estructuras necesitamos?

Antes de escribir código, identificamos qué estructura resuelve cada parte del problema:

| Parte del problema | Estructura | Apartado |
|---|---|---|
| Elegir el número, mostrar mensajes | Secuencial | [[Apuntes/1DAM_Programación/Unidad 02/2. Estructura secuencial\|2. Estructura secuencial]] |
| Repetir partidas mientras el usuario quiera (al menos una) | Bucle `do-while` | [[Apuntes/1DAM_Programación/Unidad 02/4. Estructura repetitiva (bucles)\|4. Estructura repetitiva (bucles)]] |
| Pedir intentos mientras queden y no se haya acertado | Bucle `while` con contador y conmutador | [[Apuntes/1DAM_Programación/Unidad 02/4. Estructura repetitiva (bucles)\|4. Estructura repetitiva (bucles)]] |
| Decir si es mayor, menor o se ha acertado | Condicional múltiple (`if-else if-else`) | [[Apuntes/1DAM_Programación/Unidad 02/3. Estructura selectiva (condicional)\|3. Estructura selectiva (condicional)]] |
| Entrada no numérica | `try-catch` | [[Apuntes/1DAM_Programación/Unidad 02/7. Excepciones\|7. Excepciones]] |

> [!NOTE]
> Fíjate en que **no hace falta ningún `break`**: el bucle de intentos termina por su propia condición, gracias al conmutador `acertado`. Así lo recomendamos en [[Apuntes/1DAM_Programación/Unidad 02/5. Instrucciones de salto\|5. Instrucciones de salto]].

## 10.3 El programa

```java
import java.util.Scanner;

/**
 * Juego de adivinar un número entre 1 y 100 en un número limitado de intentos.
 *
 * @author Alumnado de 1º DAM
 * @version 1.0
 */
public class AdivinaNumero {

    public static void main(String[] args) {
        // Declaraciones
        final int MAX_INTENTOS = 7;
        Scanner teclado = new Scanner(System.in);
        String respuesta;

        // Acciones
        do {                                            // Una partida por vuelta
            int secreto = (int) (Math.random() * 100) + 1;
            int intentos = 0;                           // Contador
            boolean acertado = false;                   // Conmutador

            System.out.println("He pensado un número entre 1 y 100. Tienes " + MAX_INTENTOS + " intentos.");

            while (!acertado && intentos < MAX_INTENTOS) {
                System.out.print("Intento " + (intentos + 1) + ": ");
                try {
                    int numero = Integer.parseInt(teclado.nextLine());
                    intentos++;                         // Solo cuenta si es un número

                    if (numero < secreto) {
                        System.out.println("El número secreto es MAYOR.");
                    } else if (numero > secreto) {
                        System.out.println("El número secreto es MENOR.");
                    } else {
                        acertado = true;
                    }
                } catch (NumberFormatException e) {
                    System.out.println("Eso no es un número entero. Prueba otra vez.");
                }
            }

            if (acertado) {
                System.out.println("¡Enhorabuena! Lo has adivinado en " + intentos + " intentos.");
            } else {
                System.out.println("Se acabaron los intentos. El número era " + secreto + ".");
            }

            System.out.print("¿Otra partida? (s/n): ");
            respuesta = teclado.nextLine();
        } while (respuesta.equalsIgnoreCase("s"));

        System.out.println("¡Hasta la próxima!");
        teclado.close();
    }
}
```

Observa cómo se reflejan las [[Apuntes/1DAM_Programación/Unidad 02/6. Reglas de estilo\|6. Reglas de estilo]]: el programa tiene cabecera, declaraciones y acciones; un comentario Javadoc al principio; comentarios solo donde aportan algo; una constante en mayúsculas en lugar de un «número mágico» (`7`), y sangrías que muestran qué estructura está dentro de cuál.

> [!TIP]
> Leemos la línea entera con `nextLine()` y la convertimos con `Integer.parseInt()`. Si usáramos `nextInt()` y el usuario escribiera texto, el texto se quedaría en el búfer de entrada y el bucle mostraría el error una y otra vez sin dejarle escribir. La conversión con `parseInt()` dentro de un `try` es la misma que en [[Apuntes/1DAM_Programación/Unidad 02/7. Excepciones#7.1.1. Control de excepciones en instrucciones de entrada\|7.1.1]].

## 10.4 Pruebas

Antes de dar el programa por terminado, lo probamos con **casos de caja negra** (ver [[Apuntes/1DAM_Programación/Unidad 02/8. Pruebas\|8. Pruebas]]), uno por cada situación del enunciado:

| Caso | Entrada | Resultado esperado |
|---|---|---|
| Acierto | El número secreto | «¡Enhorabuena!…» con el número de intentos |
| Número menor / mayor | Un número por debajo / por encima | «El número secreto es MAYOR / MENOR» |
| Entrada no válida | `hola`, `3.5`, línea vacía | Aviso, y el contador de intentos **no** avanza |
| Agotar intentos | 7 números incorrectos | «Se acabaron los intentos…» y el número secreto |
| Valores límite | `1`, `100`, `0`, `101` | Pistas coherentes (`0` y `101` cuentan como intento) |
| Repetir partida | `s`, `S`, `n`, otra cosa | Nueva partida solo con `s` o `S` |

Como el número es aleatorio, para probar con comodidad puedes fijarlo temporalmente (`int secreto = 42;`) o consultarlo en el **depurador** con un punto de ruptura tras generarlo (ver [[Apuntes/1DAM_Programación/Unidad 02/9. Depuración de programas\|9. Depuración de programas]]).

> [!WARNING]
> La tabla deja al descubierto un comportamiento discutible: `0` y `101` se aceptan como intentos aunque estén fuera del rango. ¿Cómo lo modificarías para que no cuenten? Las pruebas sirven precisamente para descubrir estos casos.
