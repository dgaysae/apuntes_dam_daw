La consola es la forma más sencilla de **entrada y salida de información**: el programa lee lo que el usuario teclea y le muestra los resultados en pantalla. La usas desde la primera unidad, así que aquí solo vamos a **repasar lo esencial** y a dar un paso más: **mostrar la información con formato**.

> [!TIP] ¿Necesitas repasar desde el principio?
> La entrada y salida por consola se explica con detalle en [[Apuntes/1DAM_Programación/Unidad 01/10. Apéndice. Entrada y salida por consola\|10. Apéndice. Entrada y salida por consola]] (Unidad 01).

## 0.1. Lo que ya sabes

Java gestiona la consola con tres objetos de la clase `System`, que se crean solos al arrancar el programa:

| Objeto | Para qué sirve |
| --- | --- |
| **`System.in`** | Entrada estándar (teclado) |
| **`System.out`** | Salida estándar (pantalla) |
| **`System.err`** | Salida de errores |

Para leer del teclado, la forma más cómoda es la clase **`Scanner`**:

```java
Scanner teclado = new Scanner(System.in);
System.out.print("Introduce tu nombre: ");
String nombre = teclado.nextLine();
System.out.println("Hola, " + nombre);
teclado.close();
```

> [!NOTE] `System.in` y `System.out` son flujos
> Aunque hasta ahora los hayas usado como «el teclado» y «la pantalla», en realidad son **flujos (*streams*)**: canales por los que viajan los datos entre tu programa y el exterior. En esta unidad verás que **un fichero se lee y se escribe con el mismo tipo de flujos** (ver [[Apuntes/1DAM_Programación/Unidad 06 Flujos y ficheros/2. La API clásica de Java - java.io\|2. La API clásica de Java - java.io]]). Por eso la consola y los ficheros van juntos.

### Una trampa clásica con `Scanner`

Mira este programa: pide una edad y después un nombre.

```java
Scanner teclado = new Scanner(System.in);
System.out.print("Edad: ");
int edad = teclado.nextInt();
System.out.print("Nombre: ");
String nombre = teclado.nextLine();
System.out.println("[" + nombre + "] tiene " + edad + " años");
```

Si tecleas `17`, pulsas `Enter`, y luego `Lucía`, el programa **no espera al nombre**:

```text
Edad: 17
Nombre: [] tiene 17 años
```

¿Qué ha pasado? `nextInt()` lee el número, pero **deja pendiente el salto de línea** del `Enter`. El `nextLine()` siguiente encuentra ese salto y devuelve una cadena vacía.

La solución es **descartar el salto de línea** justo después de leer el número:

```java
int edad = teclado.nextInt();
teclado.nextLine(); // descarta el salto de línea pendiente
```

```text
Edad: 17
Nombre: Lucía
[Lucía] tiene 17 años
```

## 0.2. Salida con formato

Concatenar con `+` funciona, pero tiene límites: no controlas cuántos decimales se muestran, ni puedes alinear columnas. Para eso Java ofrece la **salida con formato**.

### `printf`, `String.format` y `formatted`

Las tres usan la misma idea: escribes una **plantilla** con huecos (los **especificadores**, que empiezan por `%`) y después los valores que los rellenan, en orden.

```java
String producto = "Teclado";
int unidades = 3;
double precio = 24.5;

// 1. printf: escribe directamente en la consola
System.out.printf("Producto: %s%n", producto);
System.out.printf("Unidades: %d%n", unidades);
System.out.printf("Precio:   %.2f €%n", precio);

// 2. String.format: devuelve el texto formateado (no lo muestra)
String linea = String.format("%s x %d = %.2f €", producto, unidades, precio * unidades);
System.out.println(linea);

// 3. formatted (Java 15 o superior): lo mismo, pero sobre la propia plantilla
System.out.println("Total: %.2f €".formatted(precio * unidades));
```

```text
Producto: Teclado
Unidades: 3
Precio:   24,50 €
Teclado x 3 = 73,50 €
Total: 73,50 €
```

| Método | Qué hace | Cuándo usarlo |
| --- | --- | --- |
| **`System.out.printf(...)`** | Muestra el texto formateado | Para escribir directamente en consola |
| **`String.format(...)`** | Devuelve un `String` | Para guardar el texto, devolverlo en un método o escribirlo en un fichero |
| **`"...".formatted(...)`** | Devuelve un `String` | Igual que `String.format`, con una sintaxis más corta |

### Especificadores más habituales

| Especificador | Tipo de dato | Ejemplo | Resultado |
| --- | --- | --- | --- |
| `%d` | Entero | `printf("%d", 42)` | `42` |
| `%f` | Decimal | `printf("%f", 3.5)` | `3,500000` |
| `%.2f` | Decimal con 2 decimales | `printf("%.2f", 3.14159)` | `3,14` |
| `%s` | Texto | `printf("%s", "Hola")` | `Hola` |
| `%c` | Carácter | `printf("%c", 'A')` | `A` |
| `%b` | Booleano | `printf("%b", true)` | `true` |
| `%n` | Salto de línea | `printf("Hola%n")` | *salto de línea* |
| `%%` | El símbolo `%` | `printf("50%%")` | `50%` |

> [!TIP] Usa `%n` en lugar de `\n`
> `%n` escribe el salto de línea propio del sistema operativo (Windows usa uno distinto al de Linux o macOS). Con `printf`, `%n` es la opción correcta.

### Anchura y alineación

Entre el `%` y la letra puedes indicar la **anchura** mínima del campo. Es muy útil para mostrar tablas alineadas.

```java
System.out.printf("|%10s|%n", "derecha");    // anchura 10, alineado a la derecha
System.out.printf("|%-10s|%n", "izquierda"); // el signo - alinea a la izquierda
System.out.printf("|%05d|%n", 42);           // rellena con ceros hasta 5 cifras
System.out.printf("|%,d|%n", 1234567);       // separador de miles
```

```text
|   derecha|
|izquierda |
|00042|
|1.234.567|
```

### La configuración regional (`Locale`)

¿Te has fijado en que los decimales salen con **coma** (`24,50`) y los miles con **punto** (`1.234.567`)? Java usa la **configuración regional** (*locale*) del sistema. En un ordenador configurado en inglés, el mismo programa mostraría `24.50` y `1,234,567`.

Si necesitas un formato concreto, independientemente del ordenador, indícalo como primer argumento:

```java
Locale es = Locale.forLanguageTag("es-ES");
System.out.printf(es, "%,.2f%n", 1234567.891);        // España
System.out.printf(Locale.US, "%,.2f%n", 1234567.891); // Estados Unidos
```

```text
1.234.567,89
1,234,567.89
```

> [!WARNING] Cuidado al guardar datos en ficheros
> Si escribes números con formato en un fichero (por ejemplo, un CSV), **fija siempre el `Locale`**. Si no, un programa que se ejecute en otro ordenador podría escribir `24.50` en lugar de `24,50` y al leerlo después obtendrías errores.

## 0.3. Ejemplo completo: un ticket alineado

```java
import java.util.Scanner;

public class Ticket {
    public static void main(String[] args) {
        Scanner teclado = new Scanner(System.in);

        System.out.print("Producto: ");
        String producto = teclado.nextLine();
        System.out.print("Precio unitario: ");
        double precio = teclado.nextDouble();
        System.out.print("Unidades: ");
        int unidades = teclado.nextInt();

        System.out.println();
        System.out.printf("%-15s %8s %10s%n", "PRODUCTO", "UDS.", "TOTAL");
        System.out.printf("%-15s %8d %10.2f €%n", producto, unidades, precio * unidades);

        teclado.close();
    }
}
```

```text
Producto: Ratón
Precio unitario: 12,99
Unidades: 2

PRODUCTO            UDS.      TOTAL
Ratón                  2      25,98 €
```

> [!NOTE] La coma también vale al leer
> `Scanner` también respeta la configuración regional: en un sistema en español, `nextDouble()` espera `12,99` (con coma). Si tecleas `12.99`, lanzará una excepción `InputMismatchException`.
