[**`SharedPreferences`**](https://developer.android.com/training/data-storage/shared-preferences?hl=es-419) es una de las formas más sencillas de **persistir datos en Android**. Se utiliza para guardar pequeñas cantidades de información en formato **clave-valor** (similar a un diccionario o un mapa), que permanecen guardadas **incluso si el usuario cierra la aplicación o reinicia el dispositivo**.

Internamente se trata de un fichero XML con los datos que desde código se le van enviando.

Suele usarse para ajustes personalizados de la aplicación (modo oscuro, idioma), preferencias de notificaciones, datos de sesión (nombre de usuario, último acceso), etc.

## 6.1. Obtener las shared preferences

Para trabajar con SharedPreferences, primero debemos obtener una instancia del archivo de preferencias. Existen dos formas principales:

* `getSharedPreferences()`  
  Se usa si necesitamos varios archivos de preferencias identificados por un nombre.

* `getPreferences()`  
  Se usa desde una `Activity` cuando sólo necesitamos un archivo de preferencias para esa pantalla concreta.

Veamos cómo obtener el fichero de preferencias `MisPreferencias`:

```kotlin
val sharedPref = getSharedPreferences(
        "MisPreferencias",
        Context.MODE_PRIVATE)
```

> [!info] 
> **`Context.MODE_PRIVATE`** asegura que **sólo nuestra aplicación** pueda acceder a estos datos.

## 6.2. Guardar datos en las shared preferences

Si queremos guardar datos en `SharedPreferences` sólo tenemos que escribir en el fichero. Para ello se usa la clase interna `Editor` y lo hacemos siguiendo los siguientes pasos: llamamos al editor, añadimos los datos y confirmamos los cambios.

```kotlin
val sharedPref = getSharedPreferences(
        "MisPreferencias",
        Context.MODE_PRIVATE)

// 1. Llamamos al editor
val editor = sharedPref.edit()

// 2. Añadimos los datos en formato clave - valor
editor.putString("spNombreUsuario", "Anselmo")
editor.putInt("spEdad", 25)
editor.putBoolean("spNotificacionesActivas", true)

// 3. Confirmamos los cambios
editor.apply()
```

> [!warning] Cuidado
> Existen dos métodos para confirmar cambios:
> * `apply()`: es **asíncrono** y es el **recomendado** porque no bloquea el hilo principal de la aplicación.
> * `commit()`: es **síncrono** y devuelve un booleano. No es conveniente usarlo en el hilo de la interfaz de usuario porque puede causar parones (lag).

## 6.3. Obtener datos en las shared preferences

Para leer datos no necesitamos un editor. Directamente usamos la instancia de `SharedPreferences`.

> [!warning] Cuidado
> Siempre debemos **proporcionar un valor** por defecto en caso de que la clave no exista.

```kotlin
val sharedPref = getSharedPreferences(
        "MisPreferencias",
        Context.MODE_PRIVATE)
        
// Recuperamos los valores
val nombre = sharedPref.getString(
        "spNombreUsuario",
        "Invitado")
val edad = sharedPref.getInt(
        "spEdad",
        0)
val estaActivo = sharedPref.getBoolean(
        "spNotificacionesActivas",
        false)
        
// Uso en un TextView (ejemplo)
tvSaludo.text = "Bienvenido, $nombre"
```


## 6.4. Borrar datos

Podemos eliminar datos de la misma forma que los obtenemos: a través de la clave.

```kotlin
val editor = sharedPref.edit()
// Borrar una sola clave
editor.remove("spEdad")

// Borrar TODO el contenido del archivo
editor.clear()

editor.apply()
```
