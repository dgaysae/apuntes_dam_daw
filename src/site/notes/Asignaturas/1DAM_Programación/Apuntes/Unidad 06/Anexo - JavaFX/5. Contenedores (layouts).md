Los **contenedores** (*layouts*) son nodos que contienen otros nodos y deciden **dónde se colocan y qué tamaño tienen**. Gracias a ellos, la interfaz se recoloca sola cuando la ventana cambia de tamaño, sin que tengamos que calcular posiciones en píxeles.

## 5.1. Los contenedores más habituales

| Contenedor | Cómo coloca sus nodos | Uso típico |
|---|---|---|
| **`VBox`** | En una columna, uno debajo de otro. | Formularios sencillos, listas de botones. |
| **`HBox`** | En una fila, uno al lado de otro. | Barras de botones («Aceptar», «Cancelar»). |
| **`BorderPane`** | En cinco zonas: arriba (`top`), abajo (`bottom`), izquierda (`left`), derecha (`right`) y centro (`center`). | Ventana principal: menú arriba, contenido en el centro, barra de estado abajo. |
| **`GridPane`** | En una cuadrícula de filas y columnas. | Formularios con etiquetas y campos alineados. |
| **`StackPane`** | Apilados uno encima de otro, centrados; el último añadido queda delante. | Texto sobre una imagen. |
| **`FlowPane`** | En fila, y pasa a la siguiente cuando no caben (como el texto de un párrafo). | Galerías de iconos. |
| **`TilePane`** | Como `FlowPane`, pero en celdas del mismo tamaño. | Botones de una calculadora. |
| **`AnchorPane`** | Anclados a los bordes del contenedor, a una distancia fija. | Nodos que deben pegarse a una esquina al redimensionar. |
| **`Pane`** | En las coordenadas (`layoutX`, `layoutY`) que les demos, sin recolocarlos. | Dibujos y juegos; poco útil en formularios. |

## 5.2. Usarlos desde Java

Se crea el contenedor, se le añaden los nodos con **`getChildren()`** y se usa como raíz de la escena (o como hijo de otro contenedor):

```java
HBox botones = new HBox(10);                 // 10 píxeles de separación
Button aceptar = new Button("Aceptar");
Button cancelar = new Button("Cancelar");
botones.getChildren().addAll(aceptar, cancelar);

Scene escena = new Scene(botones, 400, 200);
```

`BorderPane` y `GridPane` no usan `getChildren()` directamente, sino métodos que indican la zona o la celda:

```java
BorderPane raiz = new BorderPane();
raiz.setTop(new Label("Cabecera"));
raiz.setCenter(new TextArea());
raiz.setBottom(botones);

GridPane formulario = new GridPane();
formulario.add(new Label("Nombre:"), 0, 0);   // columna 0, fila 0
formulario.add(new TextField(), 1, 0);        // columna 1, fila 0
```

## 5.3. Usarlos en FXML

En FXML, los nodos hijos se escriben dentro de `<children>`:

```xml
<?xml version="1.0" encoding="UTF-8"?>

<?import javafx.scene.control.Button?>
<?import javafx.scene.layout.HBox?>

<HBox alignment="CENTER" spacing="20.0"
      xmlns="http://javafx.com/javafx/21"
      xmlns:fx="http://javafx.com/fxml/1"
      fx:controller="es.dam.ejemplo.EjemploController">
   <children>
      <Button fx:id="aceptar" text="Aceptar" />
      <Button fx:id="cancelar" text="Cancelar" />
   </children>
</HBox>
```

En un `BorderPane`, cada zona es un elemento, y en un `GridPane` cada nodo indica su celda:

```xml
<BorderPane xmlns="http://javafx.com/javafx/21" xmlns:fx="http://javafx.com/fxml/1">
   <top>
      <Label text="Cabecera" />
   </top>
   <center>
      <GridPane hgap="10" vgap="10">
         <children>
            <Label text="Nombre:" GridPane.columnIndex="0" GridPane.rowIndex="0" />
            <TextField GridPane.columnIndex="1" GridPane.rowIndex="0" />
         </children>
      </GridPane>
   </center>
</BorderPane>
```

## 5.4. Combinar contenedores

Las interfaces reales **anidan** contenedores: cada zona de la ventana es un contenedor con su propia organización. Por ejemplo, una ventana típica:

- Un **`BorderPane`** como raíz.
  - Arriba, la barra de menús.
  - En el centro, un **`GridPane`** con el formulario.
  - Abajo, un **`HBox`** con los botones, alineado a la derecha.

> [!TIP] Espaciado y márgenes
> Casi todos los contenedores tienen `spacing` (o `hgap` y `vgap`) para separar sus hijos, y `padding` para dejar un margen interior. Úsalos en lugar de colocar los nodos «a ojo».
