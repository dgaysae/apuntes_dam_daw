Ya sabes organizar la ventana con contenedores ([[Asignaturas/1DAM_Programación/Apuntes/Unidad 06/Anexo - JavaFX/5. Contenedores (layouts)\|5. Contenedores (layouts)]]). Ahora veremos los nodos que se colocan dentro: los **controles**, con los que el usuario interactúa, y otros nodos como imágenes y menús. Hay muchos más; aquí tienes los más habituales.

## 6.1. Controles básicos

| Control | Para qué sirve | Métodos más usados |
|---|---|---|
| **`Label`** | Texto que el usuario no puede editar. | `getText()`, `setText()` |
| **`Button`** | Botón que lanza una acción al pulsarlo. | `setOnAction()`, `setDisable()` |
| **`TextField`** | Campo de texto de una línea. | `getText()`, `setText()`, `clear()` |
| **`PasswordField`** | Como `TextField`, pero oculta lo que se escribe. | `getText()` |
| **`TextArea`** | Texto de varias líneas. | `getText()`, `appendText()` |
| **`CheckBox`** | Casilla que se marca o desmarca. | `isSelected()`, `setSelected()` |
| **`RadioButton`** | Opción excluyente: dentro de un **`ToggleGroup`**, solo puede haber una marcada. | `isSelected()`; en el grupo, `getSelectedToggle()` |
| **`ComboBox`** | Lista desplegable para elegir un valor. | `getValue()`, `getItems()` |
| **`ListView`** | Lista visible de elementos, con selección. | `getItems()`, `getSelectionModel().getSelectedItem()` |

### Ejemplo: un formulario

**Vista** (`formulario.fxml`). Fíjate en los `import` de todas las clases que aparecen, incluidas `FXCollections` y `String`, que se usan para rellenar el `ComboBox`:

```xml
<?xml version="1.0" encoding="UTF-8"?>

<?import java.lang.String?>
<?import javafx.collections.FXCollections?>
<?import javafx.geometry.Insets?>
<?import javafx.scene.control.*?>
<?import javafx.scene.layout.VBox?>

<VBox spacing="10"
      xmlns="http://javafx.com/javafx/21"
      xmlns:fx="http://javafx.com/fxml/1"
      fx:controller="es.dam.formulario.FormularioController">
    <padding>
        <Insets top="15" right="15" bottom="15" left="15" />
    </padding>

    <fx:define>
        <ToggleGroup fx:id="grupoOpciones" />
    </fx:define>

    <Label text="Nombre:" />
    <TextField fx:id="campoNombre" />

    <Label text="Mensaje:" />
    <TextArea fx:id="areaMensaje" prefRowCount="3" />

    <CheckBox fx:id="casillaTerminos" text="Acepto los términos y condiciones" />

    <RadioButton text="Opción 1" toggleGroup="$grupoOpciones" selected="true" />
    <RadioButton text="Opción 2" toggleGroup="$grupoOpciones" />

    <ComboBox fx:id="desplegable" promptText="Selecciona una opción">
        <items>
            <FXCollections fx:factory="observableArrayList">
                <String fx:value="Opción A" />
                <String fx:value="Opción B" />
                <String fx:value="Opción C" />
            </FXCollections>
        </items>
    </ComboBox>

    <Button text="Enviar" onAction="#enviar" />
</VBox>
```

- Los `RadioButton` forman un grupo porque comparten el mismo **`ToggleGroup`**, definido en `<fx:define>` (un bloque para crear objetos que no se muestran) y referenciado con `$grupoOpciones`. Sin grupo, se podrían marcar los dos a la vez.
- Los elementos de un nodo se pueden anidar dentro de él (como `<padding>` o `<items>`) cuando su valor no es un simple texto o número.

**Controlador:**

```java
package es.dam.formulario;

import javafx.fxml.FXML;
import javafx.scene.control.*;

public class FormularioController {

    @FXML private TextField campoNombre;
    @FXML private TextArea areaMensaje;
    @FXML private CheckBox casillaTerminos;
    @FXML private ToggleGroup grupoOpciones;
    @FXML private ComboBox<String> desplegable;

    @FXML
    private void enviar() {
        String nombre = campoNombre.getText();
        String mensaje = areaMensaje.getText();
        boolean aceptado = casillaTerminos.isSelected();

        RadioButton marcado = (RadioButton) grupoOpciones.getSelectedToggle();
        String opcion = (marcado == null) ? "ninguna" : marcado.getText();

        String elegida = desplegable.getValue();   // null si no se ha elegido nada

        System.out.println("Nombre: " + nombre);
        System.out.println("Mensaje: " + mensaje);
        System.out.println("Acepta los términos: " + aceptado);
        System.out.println("Opción: " + opcion);
        System.out.println("Desplegable: " + elegida);
    }
}
```

La clase principal es como la del ejemplo de la tabla de multiplicar ([[Asignaturas/1DAM_Programación/Apuntes/Unidad 06/Anexo - JavaFX/4. Comprendiendo cómo funciona JavaFX con un ejemplo#4.1. La clase principal\|4.1]]), cargando `formulario.fxml`. La aplicación tiene más o menos este aspecto:

> [!TIP] Rellenar listas desde Java
> Lo habitual es rellenar `ComboBox` y `ListView` desde el controlador, en `initialize()`, con datos que vienen del modelo: `desplegable.getItems().addAll("Opción A", "Opción B");`.

## 6.2. Imágenes y otros nodos gráficos

- **`ImageView`**: muestra una imagen.
- **`Canvas`**: una superficie en la que se puede dibujar (líneas, figuras, texto).
- **`WebView`**: muestra una página web dentro de la aplicación (necesita el módulo `javafx.web`).

El más habitual es **`ImageView`**. En FXML, el código mínimo es este:

```xml
<ImageView fitWidth="200" preserveRatio="true">
    <image>
        <Image url="@logo.png" />
    </image>
</ImageView>
```

- La `@` indica que la ruta es **relativa al archivo FXML**: `logo.png` debe estar en la misma carpeta de `resources` que la vista (ver [[Asignaturas/1DAM_Programación/Apuntes/Unidad 06/Anexo - JavaFX/Apéndice - recursos del proyecto\|Apéndice - recursos del proyecto]]).
- `fitWidth` y `fitHeight` fijan el tamaño, y `preserveRatio="true"` evita que la imagen se deforme.

## 6.3. Menús

Para crear menús se combinan varios nodos:

- **`MenuBar`**: la barra de menús. Contiene objetos `Menu`.
- **`Menu`**: un menú desplegable («Archivo», «Editar»…). Contiene elementos `MenuItem` y puede contener otros `Menu` (submenús).
- **`MenuItem`**: una opción del menú. Al elegirla, lanza un `ActionEvent`, como un botón.
- **`CheckMenuItem`** y **`RadioMenuItem`**: opciones que se marcan y desmarcan; las `RadioMenuItem` se agrupan con un `ToggleGroup`, como los `RadioButton`.
- **`SeparatorMenuItem`**: una línea de separación.
- **`ContextMenu`**: un menú contextual, que aparece al hacer clic con el botón derecho sobre un nodo.

En este ejemplo creamos los nodos desde Java, pero también se puede hacer en FXML:

```java
import javafx.application.Application;
import javafx.scene.Scene;
import javafx.scene.control.*;
import javafx.scene.layout.BorderPane;
import javafx.stage.Stage;

public class EjemploMenu extends Application {

    @Override
    public void start(Stage ventana) {
        // Menú «Archivo»
        MenuItem nuevo = new MenuItem("Nuevo");
        MenuItem abrir = new MenuItem("Abrir");
        MenuItem guardar = new MenuItem("Guardar");
        MenuItem salir = new MenuItem("Salir");
        salir.setOnAction(e -> ventana.close());
        Menu menuArchivo = new Menu("Archivo");
        menuArchivo.getItems().addAll(nuevo, abrir, guardar,
                                      new SeparatorMenuItem(), salir);

        // Menú «Editar»
        Menu menuEditar = new Menu("Editar");
        menuEditar.getItems().addAll(new MenuItem("Cortar"),
                                     new MenuItem("Copiar"),
                                     new MenuItem("Pegar"));

        MenuBar barra = new MenuBar(menuArchivo, menuEditar);

        // Área de texto con menú contextual
        TextArea texto = new TextArea();
        texto.setContextMenu(new ContextMenu(new MenuItem("Borrar todo")));

        // Menú arriba y texto en el centro
        BorderPane raiz = new BorderPane();
        raiz.setTop(barra);
        raiz.setCenter(texto);

        ventana.setTitle("Ejemplo de menú");
        ventana.setScene(new Scene(raiz, 400, 300));
        ventana.show();
    }

    public static void main(String[] args) {
        launch(args);
    }
}
```

### Reutilizar un menú en varias vistas

Si varias vistas comparten el mismo menú, no hace falta repetirlo:

1. Diseña el menú en su propio archivo FXML, por ejemplo `menu.fxml` (a mano o con [[Asignaturas/1DAM_Programación/Apuntes/Unidad 06/Anexo - JavaFX/9. Scene Builder\|9. Scene Builder]]).
2. Inclúyelo en cada vista, en el punto donde deba aparecer:

   ```xml
   <fx:include source="menu.fxml" />
   ```

## 6.4. Controles especiales

- **`DatePicker`**: un campo con un calendario desplegable para elegir una fecha. `getValue()` devuelve un `LocalDate`. JavaFX no tiene un control equivalente para las horas.
- **`Slider`**: una barra para elegir un valor numérico dentro de un rango.
- **`Spinner`**: un campo numérico con flechas para subir y bajar el valor.
- **`ProgressBar`**: una barra que muestra el progreso de una tarea.
- **`ScrollPane`**: un contenedor con barras de desplazamiento, para contenidos más grandes que la ventana.

Un ejemplo sencillo con `DatePicker`:

```java
import javafx.application.Application;
import javafx.scene.Scene;
import javafx.scene.control.DatePicker;
import javafx.scene.layout.StackPane;
import javafx.stage.Stage;

public class EjemploDatePicker extends Application {

    @Override
    public void start(Stage ventana) {
        DatePicker selectorFecha = new DatePicker();
        selectorFecha.setOnAction(e ->
                System.out.println("Fecha elegida: " + selectorFecha.getValue()));

        ventana.setTitle("Ejemplo de DatePicker");
        ventana.setScene(new Scene(new StackPane(selectorFecha), 300, 200));
        ventana.show();
    }

    public static void main(String[] args) {
        launch(args);
    }
}
```
