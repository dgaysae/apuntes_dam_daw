Igual que en las páginas web, en JavaFX el **aspecto** de la interfaz (colores, fuentes, bordes, márgenes…) se puede definir en una **hoja de estilo CSS**, separada de la vista FXML y del código Java. Así se puede cambiar el diseño de toda la aplicación tocando un solo archivo.

El CSS de JavaFX se parece mucho al de la web, pero **no es igual**: sus propiedades llevan el prefijo **`-fx-`** (`-fx-background-color` en lugar de `background-color`).

## 8.1. Dónde va el archivo y cómo se carga

El archivo `.css` es un **recurso** del proyecto: se guarda en `src/main/resources`, en la carpeta del paquete, junto a las vistas FXML ([[Asignaturas/1DAM_Programación/Apuntes/Unidad 06/Anexo - JavaFX/3. Crear un proyecto JavaFX#3.2. Qué archivos genera el asistente\|3.2]]). Por ejemplo, `src/main/resources/es/dam/tabla/estilos.css`.

Hay dos formas de cargarlo:

- **En el FXML**, con el atributo `stylesheets` del nodo raíz. La **`@`** indica que la ruta es relativa al archivo FXML:

  ```xml
  <VBox stylesheets="@estilos.css" alignment="CENTER" spacing="20.0" … >
  ```

- **Desde Java**, añadiéndolo a la escena. Se aplica entonces a todas las vistas que se muestren en ella:

  ```java
  Scene escena = new Scene(raiz, 400, 300);
  escena.getStylesheets().add(getClass().getResource("estilos.css").toExternalForm());
  ```

> [!WARNING] Si el estilo no se aplica
> Comprueba que el archivo está en `resources` y no en `java`, en la carpeta del paquete, y que el nombre coincide exactamente, mayúsculas incluidas. Si `getResource()` no lo encuentra, devuelve `null` y el programa falla con `NullPointerException`.

## 8.2. Selectores

| Selector | Se aplica a | En el FXML |
|---|---|---|
| `.resultado` | Los nodos de la **clase de estilo** `resultado`. | `styleClass="resultado"` |
| `#campoNumero` | El nodo con ese **id**. | `fx:id="campoNumero"` (también sirve como id de CSS) o `id="…"` |
| `.button`, `.label`, `.text-field` | **Todos** los nodos de ese tipo. Cada control tiene una clase de estilo con su nombre en minúsculas, con guiones. | — |
| `.button:hover` | Una **pseudoclase**: el nodo en un estado concreto (`:hover`, ratón encima; `:pressed`, pulsado; `:focused`, con el foco; `:disabled`, desactivado). | — |

Por ejemplo, para la tabla de multiplicar de [[Asignaturas/1DAM_Programación/Apuntes/Unidad 06/Anexo - JavaFX/4. Comprendiendo cómo funciona JavaFX con un ejemplo\|4. Comprendiendo cómo funciona JavaFX con un ejemplo]]:

```css
/* Todas las etiquetas */
.label {
    -fx-font-family: "Arial";
}

/* El resultado (styleClass="resultado") */
.resultado {
    -fx-font-size: 14pt;
    -fx-text-fill: green;
}

/* El campo con fx:id="campoNumero" */
#campoNumero {
    -fx-max-width: 150;
}

/* Los botones, al pasar el ratón por encima */
.button:hover {
    -fx-background-color: lightblue;
}
```

Y, en el FXML, la etiqueta del resultado lleva su clase de estilo:

```xml
<Label fx:id="etiquetaResultado" styleClass="resultado" />
```

## 8.3. Propiedades más habituales

| Propiedad | Para qué sirve | Ejemplo |
|---|---|---|
| `-fx-background-color` | Color de fondo. | `-fx-background-color: #f0f0f0;` |
| `-fx-text-fill` | Color del texto de los controles. | `-fx-text-fill: darkblue;` |
| `-fx-font-size` | Tamaño de la fuente. | `-fx-font-size: 14pt;` |
| `-fx-font-family` | Tipo de letra. | `-fx-font-family: "Verdana";` |
| `-fx-font-weight` | Negrita. | `-fx-font-weight: bold;` |
| `-fx-font-style` | Cursiva. | `-fx-font-style: italic;` |
| `-fx-padding` | Margen interior, entre el contenido y el borde. | `-fx-padding: 10;` |
| `-fx-border-color` | Color del borde. | `-fx-border-color: gray;` |
| `-fx-border-width` | Grosor del borde. | `-fx-border-width: 2;` |
| `-fx-background-radius` | Esquinas redondeadas del fondo. | `-fx-background-radius: 8;` |
| `-fx-alignment` | Alineación del contenido (`CENTER`, `TOP_LEFT`, `CENTER_RIGHT`…). | `-fx-alignment: CENTER;` |
| `-fx-control-inner-background` | Fondo de la zona interior de algunos controles, como `TextArea` y `ListView`, donde `-fx-background-color` solo colorea el marco. | `-fx-control-inner-background: lightyellow;` |

> [!TIP] Estilos en línea
> También se puede dar estilo a un nodo concreto con el atributo `style` en el FXML (`style="-fx-text-fill: red;"`) o con `setStyle()` en Java. Úsalo solo para cambios puntuales, por ejemplo, poner en rojo un campo con un error. Para el diseño general, mejor una hoja de estilo.
