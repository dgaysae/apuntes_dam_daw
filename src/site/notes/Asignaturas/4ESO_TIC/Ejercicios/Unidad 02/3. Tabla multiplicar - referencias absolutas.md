# Ejercicio 3 - Tablas de multiplicar

> [!info]  
> Este ejercicio tiene por objeto comprender la utilización de las **referencias absolutas**.

1. Abre una hoja de cálculo nueva y copia de la siguiente tabla de multiplicar:

![hojas_calculo_ejercicio_03.png\|500](/img/user/adjuntos/4ESO_TIC/hojas_de_calculo/hojas_calculo_ejercicio_03.png)

2. Utilizando fórmulas realiza las modificaciones necesarias de tal forma que al cambiar el contenido de la celda H4 se actualice el contenido de la tabla. Así por ejemplo, si en lugar del número 7 escribiéramos el número 17, la tabla tomaría automáticamente la forma de la tabla de multiplicar del 17.
 
3. Modifica la tabla anterior para que muestre 200 primeros valores de cada tabla de multiplicar.
 
4. Guarda el resultado en tu carpeta personal con el nombre tablamultiplicar.ods.
