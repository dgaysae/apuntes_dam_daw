# Ejercicio 9 - Boletín notas

> [!info]  
> * Creación de gráficas de barras.
> * Funciones CONTAR.SI y PROMEDIO.
> * Formatos condicionales.

1. Haz una copia lo más parecida posible al siguiente boletín:

![hojas_calculo_ejercicio_09.png](/img/user/adjuntos/4ESO_TIC/hojas_de_calculo/hojas_calculo_ejercicio_09.png)

2. El color de cualquier dato relacionado con la primera evaluación es el verde, para la segunda el azul y para la tercera el naranja.
3. Aplica formato condicional a las celdas que contienen valores de notas. Si la nota es insuficiente ha de aparecer con fondo rojo y letra de color blanco, negrita.
4. La hoja ha de ser capaz de contar por si misma el número de suspensos, aprobados y sobresalientes.
5. Guarda tu ejercicio con el nombre notas.ods
